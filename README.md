# ru-deploy

**Скилл (Agent Skill) для переезда проекта с [Lovable](https://lovable.dev) на российский сервер [Cloud.ru](https://cloud.ru) — со своим доменом, бесплатным HTTPS, почтой и платежами. Всё в России, по 152-ФЗ.**

Вы сделали сайт в Lovable (Vite + React + Supabase), но из России он работает нестабильно: фронтенд, база и AI-функции живут за рубежом. `ru-deploy` — это набор инструкций и скриптов для ИИ-агента (Claude Code или Codex), который **сам** проводит вас по всему переезду: поднимает self-hosted Supabase на виртуалке Cloud.ru, подключает домен и HTTPS, настраивает почту для сброса пароля и платежи YooKassa.

**Принцип простой: агент делает сложное, вы — простое.** Вам не нужно знать ssh, Docker или YAML. Вы регистрируетесь на Cloud.ru, нажимаете кнопки в личном кабинете, копируете пару ключей — остальное агент делает за вас.

> ⚠️ **Статус:** ранняя версия. Лицензия MIT — пользуйтесь, форкайте, присылайте улучшения.

## Что вы получите

- 🇷🇺 Сайт на своём домене, на сервере в России (Cloud.ru, ВМ 2 vCPU / 4 ГБ / 30 ГБ).
- 🗄️ Своя база, авторизация, хранилище, edge-функции — self-hosted Supabase.
- 🔒 Бесплатный HTTPS (Let's Encrypt через Caddy) — настраивается автоматически.
- ✉️ Почта (сброс пароля, подтверждение email) через российский SMTP.
- 💳 Платежи YooKassa с защитой вебхука.
- 🤖 Понятный «шов» для AI-функции, если она была (GigaChat / YandexGPT).

## Что вам понадобится

- Проект на Lovable (или экспортированный из него репозиторий) у вас на компьютере.
- Аккаунт на [Cloud.ru](https://cloud.ru) и платная виртуальная машина. **Бесплатной ВМ для новых пользователей больше нет** (free tier ВМ недоступен зарегистрированным после 30.06.2026). Ориентир на 13.10.2026: ВМ 2 vCPU / 4 ГБ ≈713 ₽/мес (гарантированная доля CPU 10 %) или ≈1 295 ₽/мес (30 %), диск 30 ГБ ≈343 ₽/мес, публичный IP ≈149 ₽/мес — итого ≈1 200–1 800 ₽/мес (тарифы Evolution Compute версии 260918, с 28.09.2026, с НДС; цены меняются). Новым физлицам при привязке карты Cloud.ru даёт **4 000 ₽ бонусами на 60 дней** (акция до 31.12.2026) — это примерно 2–3 месяца сервера; дальше оплата с карты.
- При создании виртуалки вы **сами задаёте логин и пароль** — запомните их, агент попросит IP, логин и пароль, чтобы заходить на сервер (он хранит их в локальном файле `.ru-deploy/credentials.env`, который не попадает в git).
- Домен — **необязательно покупать.** По умолчанию используется бесплатный `<IP-сервера>.sslip.io` (ничего регистрировать не нужно). Хотите «красивое» имя — можно подключить свой `.ru` за ~189 ₽/год. Подробно — в [инструкции по домену](skills/ru-deploy/references/cloudru-setup.md).
- Утилита **`sshpass`** на вашем компьютере (агент подскажет установку: macOS — `brew install hudochenkov/sshpass/sshpass`, Windows — через WSL, Linux — `apt install sshpass`). Нужна, чтобы агент заходил на сервер по паролю.
- Установленный **Claude Code** или **Codex** (см. ниже).

## Установка скилла

`ru-deploy` — это [Agent Skill](https://code.claude.com/docs/en/skills): папка с `SKILL.md`, `references/` и `assets/`. Установить можно в Claude Code или в Codex.

Сам скилл лежит в этом репозитории в папке [`skills/ru-deploy/`](skills/ru-deploy). Устанавливается копированием **именно этой папки** в каталог скиллов агента (`README.md` и `LICENSE` из корня копировать не нужно).

### Вариант 1. Claude Code

**Личный скилл (доступен во всех ваших проектах):**

```bash
git clone https://github.com/nickonai/ru-deploy-skill.git /tmp/ru-deploy
cp -r /tmp/ru-deploy/skills/ru-deploy ~/.claude/skills/ru-deploy
```

**Либо для конкретного проекта** — скопируйте папку в `.claude/skills/ru-deploy` внутри репозитория проекта (так скилл коммитится вместе с проектом и доступен команде):

```bash
cp -r /tmp/ru-deploy/skills/ru-deploy .claude/skills/ru-deploy
```

После этого `SKILL.md` должен лежать прямо по пути `~/.claude/skills/ru-deploy/SKILL.md`. Перезапустите Claude Code — скилл подхватится автоматически. Проверьте: спросите «какие у тебя есть скиллы» или начните с триггера ниже.

### Вариант 2. Codex

Codex читает те же скиллы. Скопируйте ту же папку в каталог скиллов Codex:

```bash
git clone https://github.com/nickonai/ru-deploy-skill.git /tmp/ru-deploy
cp -r /tmp/ru-deploy/skills/ru-deploy ~/.codex/skills/ru-deploy
```

(если ваша сборка Codex использует другой каталог скиллов — положите папку туда; структура `SKILL.md` + `references/` + `assets/` одинаковая).

Скрипты из `assets/` и тексты из `references/` не зависят от агента — работают и там, и там.

## Как пользоваться

1. Откройте свой Lovable-проект в редакторе с установленным агентом (Claude Code или Codex).
2. Напишите агенту простыми словами, например:

   > Перенеси мой проект с Lovable на российский сервер Cloud.ru

   или один из триггеров: `ru-deploy`, «задеплоить lovable на российский сервер», «мой проект с lovable не работает в России», «свой сервер для lovable проекта».

3. Агент сам осмотрит проект и проведёт вас по шагам. От вас потребуется только:
   - зарегистрироваться на Cloud.ru и создать виртуалку (агент подскажет конфигурацию);
   - получить домен и указать его на сервер (агент даст точную инструкцию; можно бесплатный);
   - скопировать пару ключей из личных кабинетов (Cloud.ru, при необходимости YooKassa / SMTP).

   Всё остальное — установка backend, HTTPS, заливка фронта, настройка функций — агент делает сам.

4. Работа идёт **стадиями с остановками**: перед каждой стадией агент простыми словами объясняет, что будет делать, спрашивает ваше разрешение, выполняет, показывает результат — и только потом переходит к следующей. Никакого «убежал и всё сделал сам без объяснений». Стадии: осмотр → сервер и доступ → backend → сайт → (почта/платежи/AI, если нужны) → финальная проверка.

**Совет:** если чего-то не поняли — так и напишите агенту «объясни проще». Скилл специально написан без жаргона и ведёт по одному шагу за раз.

```

        ├── SKILL.md                  # точка входа: протокол стадий, карта переезда, главные принципы

        │   ├── email-smtp.md         #   почта/SMTP, SPF/DKIM/DMARC, русские шаблоны писем
        │   ├── payments-yookassa.md  #   платежи YooKassa + защита вебхука
        │   ├── ai-provider.md        #   замена AI на GigaChat / YandexGPT
        │   └── troubleshooting.md    #   типовые ошибки + финальная проверка
        └── assets/                   # скрипты и шаблоны (запускает агент)
            ├── server-setup.sh       #   установка Supabase + Caddy на сервере одним скриптом
            ├── deploy.sh             #   сборка/заливка фронта и edge-функций
            ├── gen-keys.py           #   генерация всех ключей Supabase
```

## Безопасность

- Скилл **никогда не коммитит и не показывает секреты** — все ключи живут только на сервере, в репозитории только плейсхолдеры (`assets/env.example`).
- Наружу на сервере открываются только порты `22/80/443`; API Supabase ходит через Caddy.
- Для платежей YooKassa скилл добавляет **перепроверку статуса** через API — чтобы нельзя было подделать «оплачено» (см. [payments-yookassa.md](skills/ru-deploy/references/payments-yookassa.md)).

## Вклад в проект

PR и issue приветствуются. Скилл должен оставаться понятным новичку: простой язык, один шаг за раз, агент делает тяжёлую работу сам. Если добавляете шаг или провайдера — обновите соответствующий файл в `references/` и при необходимости карту шагов в `SKILL.md`.
